Approaches

Two options, side by side. Trade-offs called out below each.

Option A — repository method
// extend the repository
async findActiveByOrg(orgId) {
  return this.model.find({ active: true });
}

Pro: layered, reusable. Con: more boilerplate.

Option B — inline query
// query in the service
const rows = await Model.find({ active: true });

Pro: fewer files. Con: violates layering — avoid.
